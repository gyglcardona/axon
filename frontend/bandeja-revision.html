Conexión Google — configuración del sistema

    
Este es el cliente OAuth con el que AXON se presenta ante Google -- se sube una sola vez, sin importar cuántas empresas o contadores lo usen después. No es una credencial de ninguna empresa en particular (esas se conectan por su cuenta, con un clic, desde "Configuración" de cada empresa).

    

    

      
      
      
Se descarga desde Google Cloud Console → Credenciales → ID de cliente de OAuth → Aplicación web. Ver docs/03-ingesta-dian/conexion-google.md para los pasos completos.

Datos maestros Contai — 

    
Contai no tiene API -- estos catálogos se cargan desde los mismos Excel que exporta/importa Contai, y las cuentas configuradas acá arman el asiento de cada factura en el plano de movimientos.
